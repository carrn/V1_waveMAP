Held-out functional differentiation
a non-circular way to ask whether a clustering of V1 neurons is "good"

This note explains a single idea precisely: a cluster solution is good to the extent that its clusters separate variables that were never used to build the clusters. It motivates the metric, writes out the math, says exactly what was computed, relates it to Carr et al. 2025, and lists the caveats.

1. Why most of our metrics can't pick a model

We clustered 606 V1 neurons with WaveMAP on a feature vector [ waveform shape , λ·laminar position ] and looked at four quality metrics vs the weight λ (and vs the cluster count K). Three of them are circular:

  • Within-cluster waveform spread can only go down as we put more weight on waveform shape — it is the clustering's own objective.
  • Within-cluster depth spread can only go down as we put more weight on laminar position — again the objective.

So both are essentially monotonic in λ and tell us nothing about whether the clusters are real; they only confirm the optimizer optimized its input. The one informative metric was the direction-selectivity index (DI) — and the reason is simple: DI was held out of the clustering. Separation on a held-out variable can't be manufactured by the objective, so it is genuine validation.

2. The fix: validate on held-out variables

The dataset carries many functional measurements that are not inputs to the clustering. We use a panel of M = 8 held-out variables:

  • direction selectivity index (DI), orientation selectivity index (OSI)
  • orientation circular variance, direction circular variance
  • orientation tuning bandwidth, simple–complex index
  • log firing rate, log ISI kurtosis (a bursting proxy)

A clustering is "good" if neurons in the same cluster have similar values of these variables and different clusters have different values — more so than you'd get by chance.

3. The math

3a. Per-variable effect size: η²

Let the clustering split the N neurons into K clusters C1,…,CK of sizes nk. For one held-out variable v (value vi for neuron i), define the grand mean and the per-cluster means:

v = (1/N) Σi vi      vk = (1/nk) Σi∈Ck vi

Split the total variability into between-cluster and total sums of squares:

SSbetween = Σk nk (vk − v)²      SStotal = Σi (vi − v)²

The effect size is the fraction of the variable's variance explained by cluster identity (the one-way-ANOVA η²):

η²(v) = SSbetween / SStotal ∈ [0, 1]

η² = 0 means clusters carry no information about v; η² = 1 means v is constant within every cluster. (Missing values are dropped per variable.)

3b. Why raw η² still can't be compared across K — the shuffle null

η² rises mechanically with K: more groups capture more between-group variance even for a random partition. So a bare η² (like the spreads) would drift with K. We remove that by comparing to a label-shuffle null with the same cluster sizes. Draw random permutations π of the cluster labels across neurons (sizes nk preserved exactly) and recompute η² each time, B = 300 times. This null has the same K and the same sizes, so it captures the chance level of η² for this particular clustering geometry.

3c. Aggregate over the panel, then standardize

For a partition, average the effect size over the M held-out variables:

T = (1/M) Σm=1…M η²(v(m))

Compute T for the real labels (Tobs) and for each shuffle (Tb, the same permutation applied to all M variables). The metric is the z-score of the observed aggregate against the null:

z = ( Tobs − meanb Tb ) / stdb Tb

z is "how many null standard deviations the clusters separate held-out function beyond chance." z ≈ 0 is chance; large positive z means the clusters are functionally meaningful. Because the null is matched in K and sizes, z is comparable across K and across λ — which the circular spreads were not.

One line of code, in words: for each (K, λ) clustering, compute the mean across 8 held-out tuning variables of "fraction of that variable's variance explained by cluster", then express it as a z-score against 300 size-matched label shuffles.

4. Exactly what was computed

  • Neurons: the 606 visually-responsive units (the paper's set).
  • Clusterings: WaveMAP (UMAP + Louvain) on [waveform, λ·position], forced to exactly K, for K ∈ {3,5,7,9} and λ ∈ {0, 0.125, 0.25, 0.5, 1, 2, 4, 8, 16, ∞} (λ=0 = shape only; λ=∞ = position only).
  • Held-out panel: the M = 8 variables in §2, none of which is a clustering input. Firing rate and ISI kurtosis are log-transformed; missing values dropped per variable.
  • Null: B = 300 label permutations preserving cluster sizes; the same permutation is applied to all variables within a draw.
  • Reported: the z-score above, per (K, λ); plus per-variable η² for three K=9 reference solutions (shape-only λ=0, the peak λ=4, position-only λ=∞).

5. How this relates to the paper

The mechanism is the paper's; the aggregate index is not. Carr et al. (Figs 3–4) use exactly this kind of label-shuffle null on held-out variables: Fig 4C compares each cluster's median DI and median amplitude to 2.5/97.5 percentile bounds from 500–1000 cluster-label shuffles ("only NS-3 differs from shuffle in amplitude and DI…"), and Fig 3 does the same for depth. What is not in the paper: (i) aggregating a whole panel of ~8 functional variables into one score, (ii) using η² (a variance-explained effect size) rather than a per-cluster median significance test, and (iii) using it to choose K and λ — the paper fixes K = 9 and has no λ. So treat the z-score as a reasonable generalization of the paper's Fig 3/4 shuffle tests, not as a published quantity.

Reading it:

  • The original cell types are real. Shape-only clustering (λ=0) already reaches z ≈ 11 — far above chance — so the waveform clusters genuinely separate held-out function. Independent validation of the paper, beyond the labels.
  • Adding moderate laminar weight roughly doubles it (z ≈ 21–27 around λ ≈ 1–4), with a sharp jump between λ = 0.5 and λ = 1, then a dip toward λ = ∞. The metric is non-monotonic — it can actually prefer a model.
  • Shape + depth beats either alone: position-only (λ=∞) is good but not the best; combining shape and a little laminar position is best.
  • Per-variable (right): direction/orientation selectivity, firing rate and bursting separate more under depth; orientation circular variance and simple–complex slightly favor shape.

7. Caveats — read it correctly

  • Laminar confound. In V1, function is itself laminar, so a depth-driven clustering separates depth-correlated functions partly for free. The rise in z with λ therefore partly reflects "depth predicts function," not strictly "better cell types." The clean, unconfounded validation of shape cell types is the λ = 0 value (z ≈ 11).
  • Not independent tests. The 8 variables are correlated (orientation measures especially); averaging η² treats them as a descriptive panel, so z is a descriptive effect size, not a multiplicity-corrected p-value.
  • Rewards any function-correlated axis. A high z says "clusters track function," not "this partition is the unique natural one."
  • Faithful-to-paper variant. To stay strictly within what the paper sanctions, report each variable's shuffle significance separately (count clusters outside the 2.5/97.5 bounds), rather than the single aggregate score.
